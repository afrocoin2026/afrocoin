# Contributing to Afrocoin

Thank you for your interest in contributing to the Afrocoin (AFR) repository.

## How to Contribute

1. **Fork the Repository:** Create your own branch from `main`.
2. **Code Standards:** Ensure all smart contracts adhere to Solidity `^0.8.20` standards and formatting rules.
3. **Commit Messages:** Use clear, descriptive commit messages.
4. **Pull Requests:** Submit PRs targeting the `main` branch with a thorough explanation of changes made.

For major architecture or financial integration proposals, please open an Issue for discussion prior to submitting code.
