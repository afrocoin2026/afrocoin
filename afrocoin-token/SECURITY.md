# Security Policy

## Supported Versions

Only the latest release and active smart contracts on the Ethereum Mainnet are supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| ERC-20 Core | :white_check_mark: |

## Reporting a Vulnerability

The Afrocoin Security Team treats security and smart contract integrity with the highest priority. If you discover a potential security vulnerability within the Afrocoin protocol or repository, please follow these steps:

1. **Do NOT open a public GitHub issue.**
2. Send a detailed report directly to our security team via email at `security@afrocoin.org`.
3. Include detailed steps to reproduce the issue, proof-of-concept (PoC) code if available, and potential impact analysis.

### Response Timeline
- **Acknowledgement:** Within 24 hours.
- **Initial Assessment:** Within 72 hours.
- **Fix & Public Disclosure:** Coordinated upon resolution.

Thank you for helping keep the Afrocoin ecosystem safe for all participants.
